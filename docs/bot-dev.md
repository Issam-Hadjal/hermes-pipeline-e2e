# bot-dev

## Responsabilité

Implémenter ce que l'issue exige, puis ouvrir une pull request vers `dev`.

## Ce que le rôle fait

- Lit l'issue GitHub comme source de vérité.
- Démarre sa branche depuis `dev`, jamais depuis `main`.
- Écrit le code ou la documentation requise.
- Ouvre une pull request vers `dev`.

## Ce que le rôle ne fait jamais

- N'approuve pas et ne fusionne pas sa propre pull request.
- Ne fusionne pas vers `main`.

## Flux

`dev` → revue par `bot-reviewer` → intégration par `bot-merger`.
